# Stories

Jira is the system of record for this course. These files exist because Session
3.3 wires the Jira MCP server, and Labs 3B and 3C run before that.

`stories/LF-05.md` is a local export in the format the `spec-implementation`
skill expects: title, description, acceptance criteria, out-of-scope, and file
pointers.

**In Lab 3D** you change step 1 of the skill to read the same fields through the
Jira MCP server instead of from this directory. The story content does not
change. Only its source does. That is the lesson.

Do not add more exports here. One is enough to prove the shape.
